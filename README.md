# Contour

A Hermes Desktop theme plugin: charcoal and white in dark mode, paper and
near-black in light mode.

- `plugin.js` registers the Contour desktop theme (Settings → Appearance).
- `andy.yaml` colors the Hermes CLI and TUI. Hermes reads it through the
  symlink `~/.hermes/skins/andy.yaml` when `display.skin: andy` is set.
